### [IconViewer](https://www.nexusmods.com/warhammer40kdarktide/mods/1078)
<img width="1250" height="835" alt="image" src="https://github.com/user-attachments/assets/19c9576f-34cf-4ea6-a9bd-3942e3aab1b5" />

A developer tool for Warhammer 40,000: Darktide to inspect and browse in-game UI textures, icons, and package assets.

**Commands:**
- `/iconview` - Open Icon Viewer

Thanks to ColorView for the idea and some of the menu code!
